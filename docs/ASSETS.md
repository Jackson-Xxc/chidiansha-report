`public/logo.png` 与 `public/favicon.svg` 用于应用自身的品牌展示。界面中的实时门店图片由接口提供，不作为本仓库的商家图片数据集。

`docs/images/desktop.png` 与 `mobile.png` 是应用界面的验收截图：采用公开测试坐标，显示候选数量和产品布局，不包含个人地址、账户、浏览器标签栏或后台凭证。截图反映验收时的版本，不保证未来平台返回相同数据。
